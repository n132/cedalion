# tcp: divide-by-zero and WARN from a locked zero `RTAX_CWND` route metric in `tcp_init_metrics()`

|  |  |
|---|---|
| Bug class | missing zero-floor on an externally-supplied threshold → DoS (WARN, wedged socket, divide-by-zero oops) |
| Subsystem | net/ipv4 (TCP route metrics) |
| Location | `net/ipv4/tcp_metrics.c:487-488` (`tcp_init_metrics()`); source `net/ipv4/metrics.c:47-56` |

## Root cause

`ip_metrics_convert()` validates exactly four metric types and lets everything else through raw:

```c
/* net/ipv4/metrics.c:47-56 */
		if (type == RTAX_ADVMSS && val > 65535 - 40)
			val = 65535 - 40;
		if (type == RTAX_MTU && val > 65535 - 15)
			val = 65535 - 15;
		if (type == RTAX_HOPLIMIT && val > 255)
			val = 255;
		if (type == RTAX_FEATURES && (val & ~RTAX_FEATURE_MASK)) { ... }
		metrics[type - 1] = val;                 /* RTAX_CWND == 0 lands here */
```

`RTAX_CWND` and `RTAX_LOCK` fall through with **no validation at all**, `val == 0` included.
`tcpm_suck_dst()` (`tcp_metrics.c:113-114, 128-129`) then copies the lock bit into `tm->tcpm_lock`
and the zero into `tcpm_vals[TCP_METRIC_CWND]` verbatim. `tcp_init_metrics()` reads it back:

```c
/* net/ipv4/tcp_metrics.c:487-493 — note the asymmetry with SSTHRESH below it */
	if (tcp_metric_locked(tm, TCP_METRIC_CWND))
		tp->snd_cwnd_clamp = tcp_metric_get(tm, TCP_METRIC_CWND);     /* no if (val) */

	val = READ_ONCE(net->ipv4.sysctl_tcp_no_ssthresh_metrics_save) ?
	      0 : tcp_metric_get(tm, TCP_METRIC_SSTHRESH);
	if (val) {                                     /* guarded — CWND is not */
		WRITE_ONCE(tp->snd_ssthresh, val);
```

The asymmetry is the tell: the `RTAX_SSTHRESH` read **three lines below** is guarded by
`if (val)`; the CWND read has no `if (val)`, no `max_t(u32, ..., 1)`.

**No reconfigure path corrects it.** A tree-wide inventory of writers to `tp->snd_cwnd_clamp` is:
`net/ipv4/tcp.c:458` (`~0` at socket init), `net/core/filter.c:5571` (the BPF setter, which *does*
guard — `if (val <= 0) return -EINVAL;`), the congestion-control modules that only ever lower it,
and this line.

**The degeneracy.** `tcp_init_transfer()` runs `tcp_init_metrics(sk)` and then immediately:

```c
	if (tp->total_retrans > 1 && tp->undo_marker)
		tcp_snd_cwnd_set(tp, 1);
	else
		tcp_snd_cwnd_set(tp, tcp_init_cwnd(tp, __sk_dst_get(sk)));
```

and `tcp_init_cwnd()` ends `return min_t(__u32, cwnd, tp->snd_cwnd_clamp);` → **0**.
`tcp_snd_cwnd_set()` is `WARN_ON_ONCE((int)val <= 0); WRITE_ONCE(tp->snd_cwnd, val);` — so this is
a directly reachable **`WARN` splat**, fatal on a `panic_on_warn` kernel.

`snd_cwnd == 0` is then sticky: `tcp_slow_start()` and `tcp_cong_avoid_ai()` both finish with
`min(..., snd_cwnd_clamp)` (`net/ipv4/tcp_cong.c:461, 485`) and re-zero it, while `tcp_cwnd_test()`
sees `in_flight (0) >= cwnd (0)` — the socket can never transmit again. A third-order effect:
`tcp_cong_avoid_ai(tp, w, acked)` reaches `u32 delta = tp->snd_cwnd_cnt / w;` (`tcp_cong.c:480`),
which is a **divide-by-zero `#DE`** if `w` is the zeroed cwnd. That leg is reached once
`snd_ssthresh` is also 0, which the same hunk produces for free: the guarded SSTHRESH reader clamps
`snd_ssthresh` down to the poisoned `snd_cwnd_clamp`, taking the socket out of slow start, and the
zero-window probe timer then supplies the ACK that the wedged cwnd would otherwise prevent.

```c
/* net/ipv4/tcp_input.c:1202-1208 */
__u32 tcp_init_cwnd(const struct tcp_sock *tp, const struct dst_entry *dst)
{
	__u32 cwnd = (dst ? dst_metric(dst, RTAX_INITCWND) : 0);

	if (!cwnd)
		cwnd = TCP_INIT_CWND;
	return min_t(__u32, cwnd, tp->snd_cwnd_clamp);   /* -> 0 */
}

/* include/net/tcp.h:1522-1526 */
static inline void tcp_snd_cwnd_set(struct tcp_sock *tp, u32 val)
{
	WARN_ON_ONCE((int)val <= 0);                     /* reachable */
	WRITE_ONCE(tp->snd_cwnd, val);
}
```

**Companion defect in the same hunk** (lower severity, same one-line fix shape):
`tcp_metrics.c:497-499` restores `tp->reordering` from `RTAX_REORDERING` with no ceiling, while
every other writer clamps to `sysctl_tcp_max_reordering` (`tcp_input.c:1296`, `:2443`, `:2585`).
With `reordering == U32_MAX` the non-SACK predicate `tp->sacked_out >= tp->reordering`
(`net/ipv4/tcp_recovery.c:147`) is constant-false because `sacked_out` is capped far lower by
`tcp_limit_reno_sacked()`, so every loss costs a full RTO instead of a fast retransmit.

## Trigger

1. `unshare -Ur -n` — CAP_NET_ADMIN in a user namespace. `rtnetlink_rcv_msg()` gates non-GET
   messages on `netlink_net_capable(skb, CAP_NET_ADMIN)` → `netlink_ns_capable(skb,
   sock_net->user_ns, CAP_NET_ADMIN)`, so the owned netns suffices. No host privilege is required
   and no special device, hardware or non-default `CONFIG` is needed.
2. Install a route carrying a *locked*, zero CWND metric via raw netlink `RTM_NEWROUTE` with
   `RTA_METRICS = { RTAX_LOCK = 1 << RTAX_CWND, RTAX_CWND = 0 }`.
   (iproute2 may refuse `cwnd 0` at the CLI; raw netlink does not, and `ip_metrics_convert()`
   does not either.)
3. Open a TCP connection over that route and close it. `tcp_update_metrics()` →
   `tcp_get_metrics(sk, dst, true)` creates the metrics block and `tcpm_suck_dst()` caches the
   lock bit and the zero. Every CWND/SSTHRESH writer in `tcp_update_metrics()` is gated on
   `!tcp_metric_locked()`, so the poison survives.
4. Open a **second** TCP connection over the same route. `tcp_init_transfer()` →
   `tcp_init_metrics()` sets `snd_cwnd_clamp = 0`, then `tcp_snd_cwnd_set(tp, 0)` fires
   `WARN_ON_ONCE` and the connection is wedged with `snd_cwnd == 0`.

To reach the divide-by-zero leg rather than only the WARN and the wedge, the per-netns
`net.ipv4.tcp_no_ssthresh_metrics_save` must be 0 (its default is 1) and a non-zero locked
`RTAX_SSTHRESH` supplied alongside the zero CWND, so that the guarded SSTHRESH reader clamps
`snd_ssthresh` to 0 as well; a Reno socket then passes `snd_cwnd == 0` directly as the divisor `w`.
The wedged socket and the poisoned metrics cache are confined to the netns the caller owns.
