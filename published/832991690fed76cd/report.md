# tracing/user_events: slab use-after-free in `trace_event_probe_cleanup()`

|  |  |
|---|---|
| Bug class | Slab use-after-free (4-byte read + 4-byte write) |
| Subsystem | `kernel/trace` (user_events, eprobe) |
| Location | `kernel/trace/trace_events_user.c`:1858 (`user_event_is_busy()`), :1864 (`user_event_free()`); `kernel/trace/trace_eprobe.c`:51 (`trace_event_probe_cleanup()`) |

## Root cause

`user_event_is_busy()` / `user_event_free()` ignore the dynamic-event refcount, so a
`user_event` is freed while an eprobe still holds `call->refcnt` and a raw `ep->event`
pointer.

The kernel has a general protocol for dynamic trace events: `dyn_event_add()` stamps
`TRACE_EVENT_FL_DYNAMIC` on the `trace_event_call`, which opts it into the `atomic_t call->refcnt`
counter, and holders take that reference through `trace_event_try_get_ref()`:

```c
/* kernel/trace/trace_dynevent.h:79 */
static inline int dyn_event_add(struct dyn_event *ev, struct trace_event_call *call)
{
	lockdep_assert_held(&event_mutex);

	if (!ev || !ev->ops)
		return -EINVAL;

	call->flags |= TRACE_EVENT_FL_DYNAMIC;
	list_add_tail(&ev->list, &dyn_event_list);
	return 0;
}

/* include/linux/trace_events.h:420 */
static inline bool trace_event_try_get_ref(struct trace_event_call *call)
{
	if (call->flags & TRACE_EVENT_FL_DYNAMIC)
		return trace_event_dyn_try_get_ref(call);   /* atomic_inc(&call->refcnt) */
	else
		return try_module_get(call->module);
}
```

`user_events` opts in — `trace_events_user.c:2201` calls `dyn_event_add(&user->devent, &user->call)` —
but it is **the only dynamic-event provider that never consults `trace_event_dyn_busy()`**.
Its busy test is:

```c
/* kernel/trace/trace_events_user.c:1858 */
static bool user_event_is_busy(struct dyn_event *ev)
{
	struct user_event *user = container_of(ev, struct user_event, devent);

	return !user_event_last_ref(user);          /* only user->refcnt */
}

static int user_event_free(struct dyn_event *ev)
{
	struct user_event *user = container_of(ev, struct user_event, devent);

	if (!user_event_last_ref(user))             /* only user->refcnt */
		return -EBUSY;
	...
	return destroy_user_event(user);
}
```

`user->refcnt` (the fd/registration counter) and `user->call.refcnt` (the dynamic-event counter) are
**disjoint**. Nothing bridges them.

Meanwhile the eprobe layer happily attaches to a user_event and takes the `call->refcnt` reference:

```c
/* kernel/trace/trace_eprobe.c:768 */
	list_for_each_entry(tp_event, &ftrace_events, list) {
		/* Skip other probes and ftrace events */
		if (tp_event->flags &
		    (TRACE_EVENT_FL_IGNORE_ENABLE |
		     TRACE_EVENT_FL_KPROBE |
		     TRACE_EVENT_FL_UPROBE |
		     TRACE_EVENT_FL_EPROBE))
			continue;                    /* user_events are NOT excluded */
		...
		if (!trace_event_try_get_ref(tp_event))
			return NULL;
		return tp_event;
	}
```

and stores the raw pointer at `trace_eprobe.c:220`: `ep->event = event;`.

So: an eprobe holds `atomic_inc(&user->call.refcnt)` and a raw pointer into the middle of
`struct user_event`, and neither protects the object. When the last user_events reference goes away,
`user_event_put()` → `delayed_destroy_user_event()` → `destroy_user_event()` runs:

```c
/* kernel/trace/trace_events_user.c:1499 */
static int destroy_user_event(struct user_event *user)
{
	int ret = 0;

	lockdep_assert_held(&event_mutex);

	user_event_destroy_fields(user);
	ret = user_event_set_call_visible(user, false);   /* -> trace_remove_event_call() */
	if (ret)
		return ret;

	dyn_event_remove(&user->devent);
	hash_del(&user->node);
	user_event_destroy_validators(user);
	...
	kfree(user);                                      /* :1524 — user->call goes with it */
	...
}
```

`user_event_set_call_visible(user, false)` → `trace_remove_event_call()` → `probe_remove_event_call()`
succeeds, because that function's guards are `call->perf_refcount` and
`file->flags & EVENT_FILE_FL_ENABLED` — an *attached but not enabled* eprobe trips neither.

The eprobe's `ep->event` now dangles into freed memory. It is dereferenced at:

- `trace_eprobe.c:274` — `ep->event->event.type`;
- `trace_eprobe.c:553` / `:827` — `create_event_filter(..., ep->event, ...)`;
- `trace_eprobe.c:58-59` — `trace_event_probe_cleanup()`:
  ```c
	if (ep->event)
		trace_event_put_ref(ep->event);
  ```
  → `trace_event_dyn_put_ref()` → `atomic_read(&call->refcnt)` then `atomic_dec(&call->refcnt)`
  (`trace_dynevent.c:41-52`) — a **UAF read and a 4-byte UAF write** at a fixed offset inside the
  freed `struct user_event`.

```c
/* kernel/trace/trace_dynevent.c:41 — the UAF read+write site */
void trace_event_dyn_put_ref(struct trace_event_call *call)
{
	if (WARN_ON_ONCE(!(call->flags & TRACE_EVENT_FL_DYNAMIC)))
		return;

	if (WARN_ON_ONCE(atomic_read(&call->refcnt) <= 0)) {   /* UAF read */
		atomic_set(&call->refcnt, 0);                  /* UAF write */
		return;
	}

	atomic_dec(&call->refcnt);                             /* UAF write */
}

bool trace_event_dyn_busy(struct trace_event_call *call)
{
	return atomic_read(&call->refcnt) != 0;
}

/* kernel/trace/trace_kprobe.c:541 — the sibling that gets it right */
static int unregister_trace_kprobe(struct trace_kprobe *tk)
{
	if (trace_probe_has_sibling(&tk->tp))
		goto unreg;

	if (trace_probe_is_enabled(&tk->tp))
		return -EBUSY;

	/* If there's a reference to the dynamic event */
	if (trace_event_dyn_busy(trace_probe_event_call(&tk->tp)))
		return -EBUSY;
	...
}
```

**Why it is not already fixed here**: `user_event_is_busy()` and `user_event_free()` are the two
places that would need `trace_event_dyn_busy(&user->call)`, and neither has it — the file contains no
reference to that helper at all. Every sibling provider added the check
(`trace_kprobe.c:552`, `trace_uprobe.c:403`, `trace_fprobe.c:869`,
`trace_events_synth.c:1564`/`:2296`). Nor does `find_and_get_event()` exclude user_events the way it
excludes kprobe/uprobe/eprobe calls.

Consequence: KASAN reports a slab-use-after-free, a 4-byte read at offset 168 of a freed
`kmalloc-cg-512` object, in `trace_event_probe_cleanup()` ← `eprobe_dyn_event_release()`; offset 168
inside `struct user_event` is `user->call.refcnt`. The `atomic_dec`/`atomic_set` that follows the
read is a 4-byte UAF **write** at that same fixed offset. Via the filter path
(`create_event_filter(..., ep->event, ...)`) the same dangling pointer yields a much richer
primitive: `call->class`, `call->class->fields` and `call->class->get_fields` are all followed, so a
controlled realloc gives a controlled pointer walk and an indirect call through `get_fields`.

Observed on `2f1baf1fc8929e6c48370be543ad028ac7ad4131` (`v7.2-rc7-93-g2f1baf1fc892`).

## Trigger

Requires `CONFIG_USER_EVENTS=y` together with `CONFIG_EPROBE_EVENTS=y` and
`CONFIG_DYNAMIC_EVENTS=y` for the code to be built at all. `CONFIG_USER_EVENTS` is enabled by
several distro configs.

Root is required for the `dynamic_events` writes: tracefs is `TRACEFS_DEFAULT_MODE 0700` and
root-owned, and `trace_fs_type` has no `FS_USERNS_MOUNT`, so there is no user-namespace mount
escape. The user_events side is reachable by any process with access to
`/sys/kernel/tracing/user_events_data` — that file is explicitly designed to be chmod'd for
unprivileged writers, and `user_event_capable()` demands `perfmon_capable()` only for
`USER_EVENT_REG_PERSIST`, which this path does not use.

1. Register a **non-persistent** user event (so it is auto-deleted when the last reference drops):
   ```c
   int fd = open("/sys/kernel/tracing/user_events_data", O_RDWR);
   struct user_reg reg = { .size = sizeof(reg), .enable_bit = 0,
                           .enable_size = 4, .enable_addr = (__u64)&enable_val,
                           .name_args = (__u64)"myevent u32 field" };
   ioctl(fd, DIAG_IOCSREG, &reg);
   ```
   `user_event_parse()` → `dyn_event_add(&user->devent, &user->call)` stamps
   `TRACE_EVENT_FL_DYNAMIC`.

2. Attach an eprobe to it — **do not enable it**:
   ```sh
   echo 'e:myep user_events/myevent field=$field' > /sys/kernel/tracing/dynamic_events
   ```
   `find_and_get_event()` (`trace_eprobe.c:768`) skips `IGNORE_ENABLE`/`KPROBE`/`UPROBE`/`EPROBE`
   calls but **not** user_events, so it does `atomic_inc(&user->call.refcnt)` and
   `ep->event = &user->call`.

3. Drop the last user_events reference. Closing the registering fd is not sufficient on its own:
   besides the fd reference, `user_events_ioctl_reg()` creates a per-mm *enabler* that holds its own
   `user_event_get()`, and per the comment at `trace_events_user.c:2530` that reference is only
   dropped when the registering task exits or execs. Once the registering task exits, both
   references go: `user_event_put()` → `delayed_destroy_user_event()` → `destroy_user_event()`.
   `user_event_is_busy()` / `user_event_free()` / `delete_user_event()` consult only
   `user_event_last_ref(user)` and never `trace_event_dyn_busy(&user->call)`, so the eprobe's
   reference is invisible; `trace_remove_event_call()` succeeds, then `kfree(user)`.
   At runtime, `events/user_events/myevent/format` disappears while `dynamic_events` still lists
   `e:eprobes/myep user_events.myevent field=$field`.

4. Remove the now-dangling eprobe:
   ```sh
   echo '-:myep' > /sys/kernel/tracing/dynamic_events
   ```
   → `eprobe_dyn_event_release()` → `trace_event_probe_cleanup()` → `trace_event_put_ref(ep->event)`
   → `atomic_read()`/`atomic_dec()` on the freed `struct user_event` — **UAF read + write**.
   Alternatively, writing a filter to the eprobe reaches `create_event_filter(..., ep->event, ...)`
   which walks `ep->event->class->fields` — a much deeper dereference chain into freed memory.

Between steps 3 and 4 the attacker controls the timing completely, so the freed `user_event` slab
slot can be reallocated with controlled contents first. The sequence is deterministic — no race, no
allocation failure required.
