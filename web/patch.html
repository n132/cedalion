Patch

Warning Do NOT send an AI-generated patch without reviewing and validating it yourself.

This page is a guide to using bugs.sh artifacts to reproduce a bug, test the provided patch or develop one, and send it to the appropriate maintainers.

Human review

We provide AI-generated patches that pass an A/B test against the PoC, but AI makes mistakes: a patch can suppress the crash without fixing the root cause, violate subsystem design, break functionality, or introduce new bugs. Treat it as a starting point, not a ready-to-send fix. Sending an unverified patch would waste maintainers’ time and burden the review process, so we share the reproduction artifacts and welcome help testing our fix or developing a better one. To keep disclosure ethical, every bug we make public is low severity or already patched, and most are security issues. When a fix is merged, we request a CVE where applicable, and the contributor receives credit for the work.

Open issues

bugs.sh has three views: Patched, Processing and Vulnerable. Processing lists open issues; it means the bug report has been sent, and your contribution can help a patch land sooner. Each issue links to its initial report on lore and to a search for related patches. Check that search before starting. If a patch has already been posted, join the discussion and help improve it, or, preferably, choose another issue that does not yet have a patch.

Reproduction

Our storage is limited, so we cannot provide a compiled kernel for every issue. Instead, bugs.sh provides the metadata and scripts needed to build the affected kernel and trigger the bug. Using bug ID 4bda3bf8e1a2b780 as an example: 

./reproduction/repro.sh build 4bda3bf8e1a2b780 --latest --host
./reproduction/repro.sh run   4bda3bf8e1a2b780 --latest --host

--host keeps the kernel source and build output in ./4bda3bf8e1a2b780-latest/, making it easy to inspect and edit the source. The script checks out the latest kernel, applies the provided configuration, compiles it, boots it with QEMU and runs the PoC.

Docker mode is also available: omit --host. To reproduce the bug on the older kernel version where we originally triggered it, omit --latest; the script then checks out the recorded commit.
